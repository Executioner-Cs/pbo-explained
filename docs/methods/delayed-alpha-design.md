# Exploratory delayed-execution alpha sensitivity

Design recorded before execution on 13 November 2026. This is an authorized new sensitivity analysis with no numerical prediction or target. It does not change the primary experiment, its thresholds, or its saved results.

Use the existing market data, total-return signal construction, 93 original crossover settings, 5 bps per position change, common sample trimming and 16 blocks. Set execution delay to 2, compared with the primary delay of 1. Report OLS market alpha, beta, 11-Bartlett-lag HAC standard error, t statistic and one-sided Normal p-value for every setting, including the originally selected 15/225. The setting selected by delayed-panel Sharpe is also identified; do not silently change the original selected setting.

Apply existing consistent SPA recentering to all 93 alphas. Recompute each alpha and beta on each joint stationary-bootstrap sample. Use 2000 replicates, mean block length 20 and fixed seed 20261118. Save the raw observed alpha vector and all bootstrap alpha vectors, together with the complete output table and runnable script as results/delayed_alpha.txt and results/delayed_alpha_bootstrap.npz, generated by experiments/delayed_alpha.py. These are modeling choices, not paper inputs. A p-value near 0.05 has Monte Carlo standard error about 0.005; use the existing 0.05 threshold without changing it after the result.

Question: does the borderline family alpha evidence reported under same-close execution persist under one additional close of delay? This check changes the realized strategy path and its return distribution as well as execution timing; it is not an isolated experiment in trading costs or causal timing skill. It remains retrospective research-factor evidence, with no validation on an executable instrument.
